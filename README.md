## 🌟 Overview

This is an interactive **3D WebGL Portfolio** built for the **Natural Language Processing (NLP)** course. It combines comprehensive technical coursework and research projects with the unfiltered, heartfelt, and humorous **Classroom Chronicles** of our semester under **Prof. Sharmila Banu**.

The portfolio features:
- **Interactive 3D Neural Universe**: Built with **Three.js**, featuring an animated Transformer Attention Core ($Q, K, V$ orbital rings), 2,200 dynamic cosmos stars, 3D section nodes, and floating collectible stars.
- **The Class Chronicles (6 Unforgettable Chapters)**:
  1. *Chapter 1: The 'Strict Mam' Psychological Scare* 😱
  2. *Chapter 2: The Real-World Analogy Magic* 🧠💡
  3. *Chapter 3: The Mythical 10-Star Quest (Balance: 0 ⭐️)* 🎯😂
  4. *Chapter 4: The Great Faculty Shuffle (The Hiatus)* 🔄
  5. *Chapter 5: Return of the NLP Legend* 👑🚀
  6. *Chapter 6: The Mind Drift vs. The 20-Mark Visual Exam Miracle* 🎨🏆
- **The Gratitude Sanctuary**: A dedicated tribute letter to Sharmila Banu Mam with honorary badges, bouquet sending, and standing ovation confetti effects.
- **The 10-Star Gamification Quest**: An interactive game where students can answer Sharmila Mam's spot-question NLP quiz or fulfill the semester legend to unlock **Full Internal Marks**.
- **Comprehensive NLP Syllabus Cosmos**: 8 in-depth modules covering Tokenization, BPE, N-grams, Word2Vec, LSTM/GRU, Transformers, BERT/GPT, RAG, and Sharmila Mam's signature real-world analogies.
- **Interactive NLP Lab**: Live in-browser tokenization, 3D vector math calculator ($King - Man + Woman = Queen$), sentiment valence analyzer, and self-attention heatmap.
- **Web Audio API Sound Engine**: Custom synthesized tactile chimes, warp whooshes, ambient harmonics, and celebration fanfare (with mute toggle).

## 🚀 How to Run the Portfolio

### Prerequisites
- Node.js (v18+ or v20+) installed on your system.

### 1. Launch Development Server
Open PowerShell or your terminal in this directory:
```powershell
cd "C:\Users\Vijay Krishnaa S\.gemini\antigravity\scratch\nlp-3d-portfolio"
npm run dev
```
Vite will start a local server at `http://localhost:3000` and automatically open your default browser.

### 2. Build for Production / Static Deployment
```powershell
npm run build
```
The optimized bundle will be generated in `dist/`. You can preview it with:
```powershell
npm run preview
```
